# 指尖绽放（bloom）—— 瞳孔散开之后的段落

落地页开场动画里「瞳孔散开」之后原本是星空 + 流星雨。这个项目把它换成：
**一双手控制的粒子花** —— 手掌张开，粒子铺满整屏；手掌捏合，聚成一朵三层花瓣的花。

> 状态：独立子项目，已跑通并可本地运行；尚未接进 `landing-app` 的开场层。

## 快速开始

```powershell
node bloom/serve.mjs                 # http://localhost:4180
node bloom/serve.mjs 4300            # 换端口
```

- **首屏自动循环**：不需要摄像头，在「花朵 ↔ 满屏」之间缓慢往返，24 秒一圈。
- 想要手势：点「开启手势」→ 才申请摄像头 + 懒加载 MediaPipe（约 0.2s）。
- 摄像头只在 `https` 或 `http://localhost` 下可用；**双击 html 用 `file://` 打开拿不到摄像头**。

### 调试参数（可组合）

| 参数 | 作用 |
| --- | --- |
| `?disperse=0.7` | 锁死扩散度（0 = 成花，1 = 满屏） |
| `?still=1` | 冻结动画与缓动（出静帧） |
| `?n=32000` | 粒子数（5000–40000） |
| `?sim=1` | 鼠标上下滑动模拟扩散度，不碰摄像头 |
| `?debug=1` | HUD：disperse / openness / hands / fps |
| `?hand=1` | 进页面直接尝试开摄像头 |
| `?cycleSpeed=4` | 自动循环加速（验收整圈用） |
| `?meteor=0` | 关掉背景流星雨层 |

## 只有两种状态

| `disperse` | 形态 |
| --- | --- |
| 0 | 三层花瓣组成的花朵 |
| 1 | 粒子铺满整个视口 |

没有"花苞/张开度"这一维：上一版还有 `open` 参数（0 = 竖直花苞），这一版整条分支删掉了。
`disperse` 是唯一运动参数，中间值就是"正在散开/正在聚拢"。

## 三层花瓣

| 层 | 半径系数 | 抬升 z | 方位错角 | 瓣宽系数 | 粒子占比 |
| --- | --- | --- | --- | --- | --- |
| 外层 | 1.00 | 0.00 | 0 | 1.00 | 46% |
| 中层 | 0.74 | 0.10 | 0.5 × (π/P) | 0.82 | 32% |
| 内层 | 0.52 | 0.20 | 1.0 × (π/P) | 0.55 | 22% |

内层"更短、更窄、更靠前、方位错开"，外中内三圈的大小差肉眼可数；配合逐层压暗
（`col *= mix(1.0, 0.72, layer/2)`）和逐层错峰的扩散时序（外层先散），层次不会糊成一团。

## 花瓣几何与"堆积"的修法

单瓣局部坐标（`r` 沿瓣长、`lat` 横向、`cup` 杯状深度）：

```
r(u)     = u^0.92 · L                      沿瓣长的半径
w(u)     = W · (1 - (2u-1)²)^0.62 · pinch  瓣宽（椭圆包络，末端收尖）
cup(u,v) = C · v² · (0.3 + 0.7u) - 0.1u²   截面杯状 + 瓣尖回卷
```

粒子按**面积均匀**采样（`r(u)·w(u)` 的 CDF 逆变换），这是"花心不堆白点"的第一道保险。

堆积/过曝的三条修法：

1. **面积均匀采样** —— 按 `u` 均匀撒会让花心密度是瓣中的十几倍。
2. **花心减密** —— `centerThin = mix(0.34, 1.0, smoothstep(0, 0.42, u))`：
   三层六瓣的基部全挤在花心，不压就会糊成一块白。
3. **同层不重叠** —— 角向半宽 `atan(W / 0.6L)` 必须 ≤ 30°（瓣间距 60° 的一半）；
   瓣宽从 0.36 提到 0.44，所以把瓣长同步提到 1.4 来保住这条。

验收里用 `blownRatio`（近饱和像素占比）量化：当前 **0.1%**（阈值 12%）。

## 手势：手掌张合（方向已修正）

```
openness = mean( 每只手的 tension )       // 0 = 握拳/捏合，1 = 完全张开
disperse = openness
```

- **手掌张开 → 粒子满屏散开；手掌捏合 → 聚成花瓣形态。**
- 双手时取两只手张开度的平均值；单手时就是该手；没有手 → 交回自动循环。
- 单只手的 `tension` 公式不变：`ratio = |tip−wrist| / |mcp−wrist|` → 逐指归一化 →
  加权平均（拇指 0.5、其余 1/1/0.9/0.7）。
- 标定入口：`?debug=1` 的 HUD 显示实时 `openness`，按自己手型调 `FINGER_RANGES`。

> 上一版这里的方向是反的（`disperse = 1 - tension`），已修正；单元测试里有一条
> 断言专门守这个方向（`张手必须比握拳更散`），防止再翻回去。

## 自动循环（没开摄像头）

```
0–2s     花朵停留
2–9s     缓慢散开（disperse 0→1）
9–12.5s  满屏停留
12.5–20s 缓慢聚合（disperse 1→0）
20–24s   花朵停留
```

三次 Hermite 插值（切线取相邻关键帧差商），速度连续，不在关键帧处顿一下。
缓动是 `v += (target − v)×0.1`（帧率归一），**离目标 < 0.004 时吸附**，不会停在半成品。

## 背景流星雨（独立一层）

`src/meteors.js`：独立 2D canvas，画在 WebGL 花层**下面**（z-index 分级），与花朵无共享状态。

- 星轨 460 条（移动端 200），半径 0.10–1.9 倍最长边，覆盖四角；
- 流星 PC 上限 150 颗 / 移动端 70 颗，生成间隔 0.018s，寿命 1.6–3.2s，
  速度 300–620px/s，冷蓝 hue 192–216，`lighter` 叠加，出生点铺满整屏；
- 拖尾用 3 段递减描边代替 CanvasGradient（每帧建渐变在软件渲染下会把帧率拖到个位数）。

## 验收

```powershell
node bloom/tests/tension.test.mjs        # 16 项：单手/双手张开度、方向和阈值
node bloom/scripts/shoot.mjs             # 两态 / 花瓣层级 / 无堆叠过曝 / 满屏 / 循环
node bloom/scripts/check-mediapipe.mjs   # 本地 wasm+模型在 CSP 下初始化并跑 detect
```

最近一次实测（1440×900，32000 粒子）：

| disperse | 亮像素 | 过曝占比 | 平均亮度 | 宽 | 高 |
| --- | --- | --- | --- | --- | --- |
| 0.00 | 29.66% | 0.1% | 46.3 | 0.586 | 0.833 |
| 0.25 | 32.37% | 0.2% | 46.5 | 0.635 | 0.859 |
| 0.50 | 52.63% | 0.1% | 41.3 | 0.872 | 0.999 |
| 0.75 | 91.99% | 0.1% | 34.0 | 0.999 | 0.999 |
| 1.00 | 99.09% | 0.2% | 31.7 | 0.999 | 0.999 |

**散开态的亮度是单独调的**（走过一次弯路）：成花态靠粒子互相叠加出亮度，散开后不再叠加，
如果沿用花朵那套逐点衰减（瓣宽窄处 0.18、瓣尖 0.75、花心减密 0.34），整屏平均亮度只有
**7.8**——看着就是一片黑。现在散开态：
点径 ×1.22、alpha 切到无位置衰减的独立通道、颜色 ×1.35、柔光雾只轻微收 15%。
平均亮度回到 **31.7**（和成花态 46.3 同一量级）。`shoot.mjs` 里有断言守着（散开态 meanLum > 30）。

自动循环 8.7s 采样：`disperse` 最高 0.989 / 最低 0.000。

## 已知限制

1. **没有真手验证**：`check-mediapipe` 用合成画面，只能证明管线通；张开度的标定
   （`FINGER_RANGES`）要真手核对，`?debug=1` 看 `openness`。
2. **只能是 https / localhost**：局域网 http 能看花，摄像头会被拒绝。
3. **Safari**：MediaPipe 1.2.3 需要 WebAssembly SIMD（Safari 16.4+）。
4. **仓库体积**：vendored 依赖约 22 MB 二进制。
5. **满屏散开是均匀随机分布**：不是星云状，也不跟随手势位置（手位置只做轻微视差）。

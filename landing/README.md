### 2.0 开场动画（eyeTutrial 眼型 → 穿过星空 → 落地页）

**来源**：上游 [Praise-Peter/EyeTutrial-website](https://github.com/Praise-Peter/EyeTutrial-website)
的《How to draw eyes》教程，已克隆进 `third_party/eyetutrial/`（`IDK.html` / `IDK.css` 原样留档）。

> ⚠️ **上游仓库里没有动画代码**：`git clone` 后只有 `IDK.html` + `IDK.css` 两个文件，
> 正文引用的 `images/`（`Step 1.png`…`Eye tut.png`）**从未提交到仓库**（GitHub API 的 tree 只有这两个 blob），
> 而且它本身是一篇静态图文教程、不是动画库。
> 所以「直接克隆拿来用」的实际含义是：**沿用它定义的眼睛画法与结构**（圆 → 上眼睑 → 虹膜瞳孔 →
> 下眼睑 → 双眼皮 → 上色 → 阴影 → 虹膜碗状受光 → 高光闪点），
> 把这条「描线 → 上色 → 高光」的流程**演成动画**，并把配色换成落地页的冷灰蓝色系。

**时序**（唯一事实源是 intro 脚本里的 `T` 对象，CSS 的 `animation-delay` 全从 `--t-*` 变量取）：

| 时刻 | 动作 |
| --- | --- |
| 0.05s | 闭眼线画出（上游 Step 1 的圆随后跟上） |
| 0.40–1.05s | 眼球圆 / 上眼睑 / 虹膜 / 瞳孔 / 下眼睑 / 双眼皮依次描出、上色 |
| 1.35–2.00s | 阴影、虹膜碗状受光、高光与闪点（Step 8 / 9 / 13） |
| 2.15s / 2.75s | 眨眼 ×2 |
| 3.05s | 视线游移（虹膜平移，眼白眼睑不动） |
| 4.55s | 镜头推进瞳孔（整只眼以瞳孔为原点放大） |
| 4.60s | 星空开始穿行（眼睛淡出后完全露出） |
| 6.45s | 深蓝幕布与星场淡出 → 浅色落地页接手 |
| 7.00s | 交棒：此刻才开始写手写标题 |

**实现要点**：

- **睁眼 / 眨眼用 `mask`**：眼裂形状（上下眼睑围出的透镜形）整体 `scaleY`，
  虹膜被眼裂裁切 —— 所以眨眼是「眼皮盖住虹膜」，而不是把虹膜压扁。
  眼睑描边与遮罩里的眼裂共用同一组 `scaleY` 动画，靠同一时序保持同步。
- **推进倍率按视口算**（`--push-scale`）：瞳孔半径 17 个单位，
  放大到「半径 ≥ 屏幕短边一半」才算推进到位。写死倍率在窄屏上会露边 ——
  眼白被一起放大，从上下漏出两条白边。所以推进开始时眼白与高光一起淡出。
- **高光在推进时必须收掉**：5 px 的高光放大 20 倍后是几个大白球，像渲染错误。
- **星空是「穿过去」不是「星云」**：星在以观察者为中心的锥体里，z 变小 → 投影向外扩散并拉出速度线；
  出生时 x/y 与 z 同比例，保证一出生就铺满屏幕。速度曲线先冲到 56 再指数减速到慢漂，
  收尾是一层安静的星场。数量跟屏幕面积走（`√(W·H)×0.45`，夹在 220~480）。
- **交棒**：落地页的流星雨**从第一帧就在跑**，只是被开场层盖着；
  开场层淡出时露出的就是已经跑热的流星雨，所以「星星变流星」是连续的，不需要额外转场。
- **配色统一到落地页色系**：眼睛线条 `#3F6D8A`、虹膜 `#5C8BA9→#31536A`、瞳孔 `#16323F`、
  眼白 `#F1F6F9→#C4D1DA`（上游 Step 7 明确说眼白不要用纯白）；
  星空段用同族的深蓝 `#0B1A23`→`#1D3C4F`，不是纯黑，收尾淡出时能接上浅色落地页。
- **跳过与降级**：
  - 右下角「跳过开场」按钮 + `Esc`；跳过后本次会话不再自动播放（`sessionStorage`），
    想重看用 `?intro=1`。
  - `prefers-reduced-motion` / 动效开关为关 / `?intro=0` / `?still=1` → **完全不播**，直接进落地页。
  - 无 JS 时开场层整层 `hidden`（默认属性，JS 才移除），页面内容照常可读。
  - 开场期间落地页 `inert`，键盘不会钻到被盖住的控件上。
- **`window.__persistReady` 的顺序坑**：intro 脚本在解析期就可能 `fire()`，
  而主脚本的 `boot()` 要等 `DOMContentLoaded` 才 `add()` —— **fire 可能早于 add**。
  所以 `add()` 必须认「已经 fire 过」的情况，否则手写标题永远不画（这个坑真实发生过）。

### 2.1 流星雨（主特效）

- **必须有辐射点**。流星雨的定义是「同一个辐射源发出的流星」。
  所有流星的方向 = 「辐射点 → 出生点」，辐射点放在**画外左上方**
  （`W×0.14, −H×0.26`）。轨迹因此天然向右上→右下汇聚成扇形。
  平行下落的直线流看起来就是「下雨」，不是流星雨。
- **出生点直接落在画面内**（`x∈[−0.08W,1.08W]`、`y∈[−0.42H,1.02H]`），
  方向再由辐射点反推。踩过的坑：先按「辐射点周围的环带」取点，
  结果一半流星生在画布外、一生成就出界被回收，屏幕上只剩 1~2 颗。
- **出生时预填拖尾**（沿反方向铺 15 个采样点）。否则随机出生点普遍离边缘很近，
  0.7 秒就飞出屏幕 → 同屏只剩几颗，且每颗都是「从一点长出来」，根本不像流星雨。
- **分层画法**（借鉴 eyeTutrial 的「线稿 → 柔光 → 上色 → 高光」）：
  1. **线稿**：拖尾分三段（尾/中/头）逐段加粗、逐段提亮，做出锥形；
  2. **柔光**：头部一段更宽更淡的描边（bloom），宽度只能到线宽的 2.0 倍 ——
     早先做到 3.6 倍时头部糊成一个「蓝色圆球」，像彗星而不像流星；
  3. **上色**：尾到头用 `createLinearGradient` 从透明渐变到深蓝；
  4. **高光**：头部实心亮点 + **预渲染**的辉光贴图（`createRadialGradient`
     每帧新建太贵，渲染一次到离屏 canvas 再 `drawImage`）。
- **浅底上必须更深**。深色底上流星靠「发光」成立，浅底上发光是看不见的 ——
  核心描边用 `rgba(52,102,128,α)`，`α` 下限抬到 **0.48**（淡的等于没有）。
- **中央内容保护区**：`.stage-main` 整块（标题 + slogan + 关键词 + CTA）范围内流星软淡出，
  否则会划过文案。边缘 34 px 线性淡出，不用硬剔除。
  **保护区尺寸只在 resize 时量一次** —— 每帧调 `getBoundingClientRect()` 会强制重排，
  是 Canvas 页最经典的性能陷阱。
- **降级**：`prefers-reduced-motion` → 固定种子（mulberry32）造静态终帧；
  `document.hidden` 停 rAF；`resize` 180 ms 节流；`?still=1` 供截图；
  DPR 上限桌面 2 / 窄屏 1.5；窄屏流星预算 20（桌面 44）并整体降速 0.62。
- **密度靠生成间隔，不靠上限**：`maxMeteors` 只是天花板，实际同屏数量 = 生成速率 × 在屏寿命。
  间隔按「0.8 秒期望寿命」折算（`800 / maxMeteors`）：间隔给太大时寿命比预期短，
  屏幕上就铺不满（实测按 2400ms 折算时同屏只有 21~37 颗，改为 800ms 后稳定 42~44 颗）。
  44 颗时 headless 实测仍 ~120 fps（每颗 4 个渐变 + 1 张预渲染辉光贴图）。

### 2.2 手写标题「Persist」（点缀 1）

> **2026-11-20 已回退**：这一版曾重绘成全小写 `persist`（修 `r` 笔画），
> 用户要求**恢复上一版**（大写 `Persist`、`skewX(-11)` 组变换、11 条路径、`stroke-width 7.5`、
> 宽度 `clamp(230px,42vw,460px)`），**字形与逐笔浮现动画原样保留，不重绘**。
> 唯一改动：viewBox 从 `-48.3 -180 374.3 196` 收到 `-6.0 -176.0 342.3 186.0` ——
> 旧 viewBox 的倾斜符号算反了，左边多留了约 52 px 空档，整词因此偏右、
> 右端还压着 `t` 的收笔。字形本身一字未动。

- **路径自绘，零 webfont 依赖**。这是刻意选择：手写体 webfont（如 `Sacramento` / `Segoe Script`）
  在不同浏览器 / 系统下字形不一致 —— 更早的 `Hello world` 就是这么翻车的。
  自绘路径则 100% 跨浏览器一致。
- **笔画推进**：每条路径量出 `getTotalLength()`，设为 `--len`，
  `stroke-dasharray` / `stroke-dashoffset` 走 CSS 变量，按笔画顺序错峰归零。
  **坑**：长度和偏移**必须走 CSS 变量，不能用内联 `style.strokeDashoffset`** ——
  内联优先级高于 `.is-drawn` 类，归零动画就永远不会生效（标题会一直停在「完全隐藏」）。
- **倾斜用 `<g transform="skewX(-11)">`**（沿用上一版写法）：skewX 是仿射变换，
  可以对控制点直接换算 `x' = x + y·tan(−11°)`，所以生成器用同一套公式算 viewBox。
  另一条路是**把倾斜烘焙进路径坐标**（不用 transform）—— 也能做，但 viewBox 要另行补偿。
- **烘焙时的坑**（重绘版踩过，留档）：`String.replace` 的回调是**每个数字**触发一次，
  数字在 path 里交替出现 `x,y,x,y…`，必须按奇偶位分别输出变换后的 `x'` 与未变的 `y`。
  早先版本按「坐标对」输出，一半匹配拿到 `undefined` → SVG 解析中断 → 笔画整段断裂。
- **手写体的通用教训**（重绘版验证过，仍然成立）：
  - 全小写时 `p` **必须下伸到基线以下**，否则读成大写 `P`；
  - `r` 的肩部必须停在高位、末端带小上挑钩，接在竖笔顶端形成平滑拱形会读成 `n`；
  - `e` 是**两笔**（横杠 + 弧），只画闭环读成 `o`，弧把横杠左端包住读成 `θ`；
  - `s` 下环要多甩一点，否则整词缩到 460 px 时上下两环糊成一团、读成 `y`；
  - **画完必须单独放大看一眼**，整页截图太小看不出这种问题。
- 字形由 **`scripts/wordmark.mjs`** 生成（已入库，是字形的唯一事实源），
  产出即最终 `<svg>` 块，**直接粘贴**——手抄进 HTML 出过错（P 的路径和生成器对不上）。
  改完要 ① 单独放大审查每个字母；② 按实际显示宽度（460 px）再看整词。
  生成器同时产出逐字母审查页与整词预览（`.workbuddy/tmp/`，不入库）。

### 2.3 眼睛标记（点缀 2）

- 造型借鉴 [eyeTutrial](https://github.com/Praise-Peter/EyeTutrial-website) 的画法：
  **圆 = 虹膜，上下眼睑夹出杏仁形，最后加一点高光**。纯 SVG + clipPath，零外部请求。
  （同一套画法在 §2.0 的开场动画里被放大成主角。）
- 虹膜 / 瞳孔跟随光标微动（上限 ±2.6 px，每帧向目标插值 12%）。
  只做「活着」的效果，不抢文案；触摸设备无光标 → 静止；减动效 → 静止。
- 5.6 秒循环眨一次眼（`scaleY` 1 → 0.08 → 1，`transform-box: fill-box`）。
- **虹膜 / 瞳孔是有意义的图形**，按 WCAG 非文本对比度门槛 3:1 处理：
  虹膜 `#5C8BA9` 对页面底 3.41:1，瞳孔 `#16323F` 对虹膜 3.66:1。
  早先用 `--green` 55% 透明度填充，实测只有 2.66:1。

### 2.4 动效开关

- 顶栏右上角开关，`aria-pressed` + `localStorage`（`persist.motion`）持久化。
- 关掉后：流星雨停住（rAF 取消）、手写标题直接显示终态。
- 默认值跟随 `prefers-reduced-motion`（系统减动效 → 默认关）。
- **验收必须读实时状态**：页面暴露 `window.__persistLandingState()`，
  自检块 `?selftest=1` 只是它某一时刻的快照。用快照比较「关掉前后帧数是否还在涨」测不出来。

### 2.5 渐进增强与无障碍

- 无 JS 时：手写标题走 `html.no-js` 分支，**描边直接可见**（`stroke-dasharray: none`）——
  不能让标题在没有 JS 时是一团空气；slogan / 关键词 / CTA / 备案信息全部完整可读。
  **开场层默认带 `hidden` 属性**，只有 JS 才会移除它 —— 无 JS 时整层不出现，不会挡住任何内容。
- SVG 有 `role="img"` + `aria-label="Persist"`；装饰性画布与眼睛标记 `aria-hidden`。
- 焦点可见：所有可点元素都有 `:focus-visible` 描边。
- 开场层期间落地页 `inert`：视觉上被盖住，键盘也不该能钻进被盖住的控件。

## 3. `home.html`：介绍首页实现要点

9 个段落（顺序即源码顺序）：首屏 `#top` → 问题 `#problem` → 怎么工作 `#how`（5 步）→ 三个模块 `#product` → AI 报告 `#report` → 长期视角 `#long`（7/30/90 天）→ 隐私 `#privacy` → 适合谁 `#who` → 内测 `#beta` → 页脚。锚点与导航一一对应，无失效锚点。

- **零图片**：所有图形都是 CSS 渐变、`box-shadow`、内联描边 SVG（`stroke` 系图标）。首屏「今日卡片」是纯 CSS 摆出来的示意，不是截图。
- **动效只用 `opacity` / `transform`**：导航 `is-stuck` 在 `scrollY > 12` 切换（rAF 节流）；`.reveal → .in` 由 `IntersectionObserver` 驱动，并有 `delivered` 兜底与首帧强制放行；`prefers-reduced-motion` 下全部直出。
- **仅两个产品入口**：`data-enter="demo"` 与 `data-enter="guest"` 交给同一个事件委托，分别进入 `/app/?mode=demo` 与 `/app/?mode=guest`。页面不存在 `product` / `beta` / `blank` / `owner` 入口；桌面构建不提供真实 AI 入口，完整产品只在作者自有移动端 App。

## 4. 配色与对比度（含对 `docs/工程约定.md` §3 的偏离）

**落地页与介绍首页现在用同一套浅色产品色系**（2026-11-20 第二轮重做统一）。
落地页不再做深色 —— 深色是上一版「炫技优先」的选择，与「统一到产品色彩体系」
冲突，而且 ASCII 字符流这种效果本来就依赖深底，换成流星雨后不再需要。

落地页直接采用 `app/src/styles/home-v3.css` 的令牌，页面背景渐变与 app 的
`body` 背景**逐字一致**：

```css
background:
  radial-gradient(circle at 8% -8%, rgba(255,255,255,.9), transparent 34%),
  radial-gradient(circle at 105% 110%, rgba(126,173,200,.14), transparent 36%),
  var(--bg);           /* #F4F7F9 */
```

| 令牌         | 值        | 用途                        | 对页面底对比度 |
| ------------ | --------- | --------------------------- | -------------- |
| `--ink`      | `#202830` | 主文字 / slogan             | 13.87         |
| `--soft`     | `#4D5965` | 正文                        | 6.66          |
| `--muted`    | `#55616D` | 顶栏链接 / 关键词 / 开关    | 5.88          |
| `--faint`    | `#616D79` | 注脚 / 页脚备案             | 4.91          |
| `--deep`     | `#467692` | 手写标题 / 强调 / 眼睑 / 流星 | 4.57          |
| `--green`    | `#6D9FBD` | 动效开关圆点 / 网格         | 2.66（仅装饰） |
| 主按钮文字    | `#FFFFFF` | 压在 `--deep` 渐变上        | 4.92 / 5.29 / 5.85（三档） |

**开场动画是唯一有意用暗场的地方**：深蓝幕布 `#0B1A23`→`#1D3C4F`、星空底色 `#0B1A23`。
这不是另一套配色，而是同一色系的**暗端**（`--deep #467692` 的低明度版本）——
收尾时幕布淡出、接上浅色落地页，两者是同一条色带的两头。
暗场里的文字/按钮（跳过按钮 `#D3E6F1`）按暗底重新算对比度，不套用浅底的令牌。

> **11px 是小字，对比度门槛 4.5** —— 页脚备案信息用**实色**（`#616D79`），
> 不能用半透明（合成后不达标）。
> **主按钮渐变的三档都必须对白字 ≥ 4.5** —— 上档不能比 `#467692` 更亮，
> 否则白字掉到 4.2 以下。
> **虹膜 / 瞳孔按非文本图形门槛 3:1 处理**：虹膜 `#5C8BA9` 对底 3.41，
> 瞳孔 `#16323F` 对虹膜 3.66。

**介绍首页仍走「浅色低饱和、沿用产品整体色调」**：页底 `#F4F7F9`、卡片 `#FBFCFD`/`#FFFFFF`、条纹带 `#EDF2F6`、页脚 `#EAEFF3`，强调色仍是 `#6D9FBD` 一脉。

| 令牌        | 值        | 用途                 |
| ----------- | --------- | -------------------- |
| `--ink`     | `#202830` | 标题                 |
| `--soft`    | `#4D5965` | 正文                 |
| `--muted`   | `#55616D` | 次要正文             |
| `--faint`   | `#616D79` | 注脚 / 说明          |
| `--accent`  | `#6D9FBD` | 仅非文字装饰         |
| `--accent-ink` | `#3C6883` | 强调色系上的文字     |

**与 §3 的三处有意偏离**（为达标，不是随手改）：

1. `--muted` `#74808C` → `#55616D`、`--faint` `#9AA5AF` → `#616D79`：原值对 `#F4F7F9` 只有 3.75 / ≈2.6，正文读不清。
2. 主按钮由浅蓝改中深蓝 `linear-gradient(180deg,#4A7A96,#44738F 58%,#406E89)`：白字对三档分别为 **4.65 / 5.13 / 5.51**（原 `#6D9FBD` 上仅 2.86）。
3. 新增 `--accent-ink:#3C6883` 专供「浅蓝底上的文字/图标」：5.29（对 `--accent-soft`）、6.00（对白）、5.18（对页脚）。

22 组色对实测全部达标（正文门槛 4.5、图形 3.0），层次单调：ink 13.87 > soft 6.66 > muted 5.88 > faint 4.91。`#6D9FBD` 只留在圆点、细线、光晕、进度条渐变等非文字处，是入口页到首页的视觉桥梁。

## 5. 验证方法（可复现）

无头浏览器容易骗人，判据必须来自**真实渲染后的测量**，不是「看起来对」：

- 工具：`app/node_modules` 里的 Playwright（`chromium.launch({ headless: true })`），直接开 `file://`，可 `evaluate`、截图、`emulateMedia`、`javaScriptEnabled:false`。
- **落地页一条命令**：`node scripts/check-landing.mjs`（加 `--shots` 顺带重拍 `landing/preview/landing-*.png`）。它断言：
  - 6 视口（1920/1440/1280/768/390/360）无横向滚动、手写标题与 CTA 落在首屏内；
  - 手写标题的 11 条路径**逐条**被画出（`wmDrawn === wmPaths`），不是一下子全出现；
  - 流星雨：数量 > 0、拖尾点数 ≥ 流星数、帧数递增；
  - **流星汇聚到同一辐射点**：每道轨迹方向与「辐射点→头部」的夹角 ≤ 0.2 rad
    （防退回「各飞各的」= 下雨）；同时角度跨度 ≥ 0.1 rad（防退化成完全平行的直线雨）；
  - 页面里**不再有仿真终端**；
  - 眼睛标记存在，且光标移动后虹膜偏移生效且不越界（≤ 3.2 px）；
  - 关掉 JS 时标题**描边可见**（不能是一团空气）、slogan、关键词、两个 CTA、备案信息完整可读、
    **开场层整层不出现**；
  - `prefers-reduced-motion` 下出静态终帧且画布非空、标题直接终态；
  - **动效开关**：关掉后帧数冻结（流星雨真的停了）、标题直显终态、再开帧数继续增长；
  - **开场动画**：`?intro=1` 时 1.3 s 眼睛在场且落地页标题被按住（还没开始写）、
    5.9 s 星空画布有像素、8.5 s 开场结束（`data-intro=off`）且标题全部画完；
    点「跳过开场」立刻交棒并把标题写完；`?intro=0` 与减动效下**开场层完全不出现**；
  - 关键色对对比度（正文门槛 4.5 / 图形 3.0）。
  页面内置 `?selftest=1` 会把真实测量值写进 DOM，脚本据此断言。
  **另暴露 `window.__persistLandingState()` 返回实时状态** —— 动效开关这类「前后比较」必须读实时值，
  自检块只是一次性快照，用快照测不出帧数有没有停。
  **落地页本体一律带 `?intro=0`**：开场层会盖住页面 7 秒，布局/流星/标题这些断言测的是落地页本身。
- 首页判据：6 视口（1920/1440/1280/768/390/844 横）无横向滚动、恰好 9 个 section、58 个 `.reveal` 全部进入且不透明、4 个 toast 都真的出现、降级路径（减动效 / 关 JS）内容完整、无控制台报错。
- 三处已知坑：① `--dump-dom` + `--virtual-time-budget` **不会**冲刷异步回调，`setTimeout` / rAF 里写的 DOM 永远看不到，只有加载期同步写入才算数；② `--screenshot` 在超高窗口（如 1920×8000）会挂死；③ 探针 HTML 页面里用字符串拼接构造结果文本（如 `'SYN-'+'OK'`），否则正则可能匹配到 `<script>` 源码里的字面量而误判。
- **字形必须单独放大审查**：整页截图里手写标题只有几百像素，`e` 断开成 `ep`、`r` 读成 `n`、
  `s` 读成 `y`、`p` 读成大写 `P` 这类问题根本看不出来。
  做法：把单个字母的路径抽出来，用大尺寸单独渲染成 PNG 再看；整词还要按**落地页实际显示宽度**
  （460 px）再看一遍 —— 字母单看正常、缩到整词尺寸就糊成一团的情况很常见。
- 另两条只读门禁：`node scripts/check-og-meta.mjs`（分享卡标签）、`node deploy/scripts/render-site-info.mjs --check`（备案占位一致性）。

## 8. 维护约定

- 不得引入外链资源：无 CDN、无第三方字体、无图标包、无统计脚本、无第三方动效库。
- **公开页不得触发真实模型调用**：页面必须纯静态，示例 AI 内容只能是写死的文本并标明「依据当时的记录」。服务端侧另有 token 门 + 双配额兜底，但**公开页本身不该发请求**。
- 改完必须重跑四项：22 组对比度、6 视口布局与滚动、`prefers-reduced-motion`、关闭 JS。
- **开场动画的时序只改一个地方**：intro 脚本里的 `T` 对象；CSS 的 `animation-delay` 全从 `--t-*` 变量取，
  不要在 CSS 里另写死秒数（两处各写一遍必然走偏）。
- **推进倍率 `--push-scale` 由 JS 按视口算**，别写死：写死会在窄屏露边（眼白变成上下两条白边）。
- 上游来源留档在 `third_party/eyetutrial/`（`IDK.html` / `IDK.css` 原样 + README 说明），
  **不要改上游文件**；动画实现在 `landing/index.html` 内联，不依赖上游目录。
- 图片来源 `picture/` 不入库；`assets/` 里的派生 WebP 与 LQIP 入库。
- 文档分工：本文管**落地页与介绍首页的实现细节**；[`docs/落地页与入场动画方案.md`](../docs/落地页与入场动画方案.md) 管「跳转参数 + 跳过去之后的运行模式」；[`docs/网站设计层交接-2026-11-19.md`](../docs/网站设计层交接-2026-11-19.md) 是**重新设计的单一入口**。

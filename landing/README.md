## 2. `index.html`：落地页实现要点（2026-11-20 重做为科技展示型 · 浅色产品色系）

**定位变了**：这一页不再是「3 秒看懂产品价值」的说明页，而是**炫技展示页**——
只留项目名、一句 slogan、几个关键词，**详细内容全部留给 `home.html`**。
产品介绍页负责说清楚「这是什么」，这一页负责「让人愿意看下去」。

**入口边界（2026-11-20 用户拍板）**：**落地页不得有任何直达产品的入口**。
原先的「立即体验 → `/app/?mode=demo`」已删除，落地页现在只把用户送到
`home.html`，由介绍首页统一承接「看演示 / 自己试试」两个动作。

> 为什么这条要写成硬约束而不是「先这么着」：落地页是**第一个**看到的产品界面，
> 如果它能一步跳进产品，介绍首页就失去了「先讲清楚再进产品」的意义 ——
> 而这正是重做的初衷。顺手加个「立即体验」是最容易被无声破坏的地方：
> 它不会报错、不会崩，只会让叙事顺序悄悄倒过来。

两个 CTA 都指向介绍首页，但落点不同（**不是两个一模一样的按钮**）：

| 按钮 | 文案 | 目标 | 为什么这么定 |
| --- | --- | --- | --- |
| 主 | 看看它能做什么 | `home.html` | 首页首屏（收益 → 能力 → 信任 → 转化） |
| 次 | 先看一段解读 | `home.html#story` | 直接落在「一天结束时的 AI 解读」，产品最打动人的一段 |

- note 小字同步改成「不用注册。数据默认只存在你自己的设备上。」——
  与首页 `#trust` 段的「默认只存在你自己的设备上」**同源**。
  原句「演示数据只留在你自己的浏览器里」提到「演示」，但落地页已无演示入口，文案会指错方向。
- **`scripts/check-landing.mjs` §0 段**把这条约束做成了断言：
  静态扫全部 `href`/`src`，出现任何 `/app/` 直接判失败；
  CTA 的链接必须全部以 `home.html` 开头。

**色调与产品对齐**：落地页不再是深色霓虹青，而是直接采用
`app/src/styles/home-v3.css` 的令牌（`--bg #F4F7F9` / `--deep #467692` / `--green #6D9FBD`），
页面背景渐变与 app 的 `body` 背景**逐字一致** —— 落地页和产品是同一张纸。
唯一有意偏离：产品里的 `--muted #74808C` / `--faint #9AA5AF` 在本底色上只有 3.75 / ≈2.6，
落地页改用 `#55616D` / `#616D79`（5.88 / 4.91）。

**动效预算**（刻意克制，只 1 主 + 2 点缀）：

| 角色 | 效果 | 实现 |
| --- | --- | --- |
| 主特效 | 满屏流星雨（仅在入场层交棒段）：星空底图 + 几何圆弧星轨 + 渐变尾迹流星 | Canvas 2D + 原画质星空 data URI |

#### ★ 「字符过于密集」的四个成因与修法

这一版重写的起因，就是网页复刻版看起来「字符过于密集」。逐项定位后有四个原因，
**全都不在引擎里，而在调用侧**：

| 成因 | 修法 |
| --- | --- |
| 字符格取错：用了 8×17 / 44 行 | 换成原版实测的 **8×15 / 30 行**（`78×30` 网格）。行数一多，眼睛在画面里占的字符行数翻倍，皮肤纹理就把它淹了 |
| 字体加了 `bold` | 去掉粗体。原版是 Consolas **常规体** 14px，粗体笔画粗一倍，格与格之间的细缝直接被糊掉 |
| 字号按格高算（`ch × 0.68`） | 改成 **格宽 × 1.75**（Consolas advance ≈ 0.55em）。原版 14px / 格宽 8px ≈ 横向填满一格，纵向只占 6 成 |
| 配色把原版的 `×1.15` 乘了两次 | 引擎输出的 `q` **已经是** `clip(cells × 1.15)` 量化后的值，不能再乘。重复乘会把暗部皮肤系统性抬高 → 满屏亮橙字符、纯黑留白全部消失 |

另外还有一个**隐藏的元凶**：差量重绘时如果只画新字符、**不擦旧字形**，
旧字符的残笔会一层层堆在画布上（`X` 换成 `,` 只盖住一小块）。
几帧之后画面就糊成一片，而且推进到瞳孔铺满时整屏金色残影永远擦不掉 ——
所以 `drawFrame()` 里字符一变就先 `fillRect` 擦背景色再画。

#### ★ 心形星云怎么彻底关掉

引擎里的云雾生成条件是 `nebAmt = ease((t − (T_Z0 + 3.5)) / 8.0)`，
而 `CFG.T_HEART = 1e6` **只能**保证「心形」不出现 —— 云雾本体照样会生成，
画面里会出现一团粉紫色的圆形雾。

真正的开关是**时间线约束**：只要 `T_ZD < 3.5`，推进结束的那一刻云雾还没开始生成；
收尾段再压到 `nebAmt < 0.008`，画面就完全干净。**当前值** `T_Z0 = 6.2 / T_ZD = 3.2`，
`T.meteor = 6.2` / `T.wait = 9.4` —— 9.4 秒进入界面并等点击，不自动交棒（历史值 4.6/7.8）。

#### 其他实现要点

- **引擎参数与原版逐项对齐**：`{ smooth: 0, contrast: 0, levels: 0, hash: 0.07 }`。
  引擎默认的 `contrast`（自动色阶拉伸）会把中间调压平、把暗部推进宽字符区，
  是「密成一片」的推手；Python 原版没有这一步。
- **取色（当前为第十一轮灰蓝三色）**：原文第七轮的「单蓝亮度映射」已废弃（会把色相抹成只有深浅）。
  现行 `palette()` 按「暖度识别虹膜 + 亮度区分瞳孔/巩膜」把引擎 RGB 重映射到产品灰蓝三色相：
  瞳孔 `#1a2a36` / 虹膜 `#467692` / 巩膜 `#c7dae6`。详见本节开头「第十二轮现行实现」。
- **交棒**：9.4s 进入融合界面（两场景）等点击；点击空白处（或 `Enter`/`Space`）后才 `finish()`
  淡出开场层，落地页标题才开始逐笔写。
  落地页本身**没有流星雨**（已移到入场层），是一张安静的浅灰蓝纸。
- **跳过与降级**：
  - 右下角**「关闭动画」按钮**（全程可见）：点击立即 `dispose()` 停掉眼睛与流星雨引擎、
    释放资源并清定时器，再交棒落地页。

  - `prefers-reduced-motion` / 动效开关为关 / `?intro=0` / `?still=1` → **完全不播**，直接进落地页。
  - 无 JS 时开场层整层 `hidden`（默认属性，JS 才移除），页面内容照常可读。
  - 开场期间落地页 `inert`，键盘不会钻到被盖住的控件上。

### 2.2 手写标题「Persist」（点缀 1）

> **2026-11-20 已回退**：这一版曾重绘成全小写 `persist`（修 `r` 笔画），
> 用户要求**恢复上一版**（大写 `Persist`、`skewX(-11)` 组变换、11 条路径、`stroke-width 7.5`、
> 宽度 `clamp(230px,42vw,460px)`），**字形与逐笔浮现动画原样保留，不重绘**。
> 唯一改动：viewBox 从 `-48.3 -180 374.3 196` 收到 `-6.0 -176.0 342.3 186.0` ——
> 旧 viewBox 的倾斜符号算反了，左边多留了约 52 px 空档，整词因此偏右、
> 右端还压着 `t` 的收笔。字形本身一字未动。

- **路径自绘，零 webfont 依赖**。这是刻意选择：手写体 webfont（如 `Sacramento` / `Segoe Script`）
  在不同浏览器 / 系统下字形不一致 —— 更早的 `Hello world` 就是这么翻车的。
  自绘路径则 100% 跨浏览器一致。
- **笔画推进**：每条路径量出 `getTotalLength()`，设为 `--len`，
  `stroke-dasharray` / `stroke-dashoffset` 走 CSS 变量，按笔画顺序错峰归零。
  **坑**：长度和偏移**必须走 CSS 变量，不能用内联 `style.strokeDashoffset`** ——
  内联优先级高于 `.is-drawn` 类，归零动画就永远不会生效（标题会一直停在「完全隐藏」）。
- **倾斜用 `<g transform="skewX(-11)">`**（沿用上一版写法）：skewX 是仿射变换，
  可以对控制点直接换算 `x' = x + y·tan(−11°)`，所以生成器用同一套公式算 viewBox。
  另一条路是**把倾斜烘焙进路径坐标**（不用 transform）—— 也能做，但 viewBox 要另行补偿。
- **烘焙时的坑**（重绘版踩过，留档）：`String.replace` 的回调是**每个数字**触发一次，
  数字在 path 里交替出现 `x,y,x,y…`，必须按奇偶位分别输出变换后的 `x'` 与未变的 `y`。
  早先版本按「坐标对」输出，一半匹配拿到 `undefined` → SVG 解析中断 → 笔画整段断裂。
- **手写体的通用教训**（重绘版验证过，仍然成立）：
  - 全小写时 `p` **必须下伸到基线以下**，否则读成大写 `P`；
  - `r` 的肩部必须停在高位、末端带小上挑钩，接在竖笔顶端形成平滑拱形会读成 `n`；
  - `e` 是**两笔**（横杠 + 弧），只画闭环读成 `o`，弧把横杠左端包住读成 `θ`；
  - `s` 下环要多甩一点，否则整词缩到 460 px 时上下两环糊成一团、读成 `y`；
  - **画完必须单独放大看一眼**，整页截图太小看不出这种问题。
- 字形由 **`scripts/wordmark.mjs`** 生成（已入库，是字形的唯一事实源），
  产出即最终 `<svg>` 块，**直接粘贴**——手抄进 HTML 出过错（P 的路径和生成器对不上）。
  改完要 ① 单独放大审查每个字母；② 按实际显示宽度（460 px）再看整词。
  生成器同时产出逐字母审查页与整词预览（`.workbuddy/tmp/`，不入库）。

  不能让标题在没有 JS 时是一团空气；slogan / 关键词 / CTA / 备案信息全部完整可读。
  **开场层默认带 `hidden` 属性**，只有 JS 才会移除它 —— 无 JS 时整层不出现，不会挡住任何内容。
- SVG 有 `role="img"` + `aria-label="Persist"`；装饰性画布与眼睛标记 `aria-hidden`。
- 焦点可见：所有可点元素都有 `:focus-visible` 描边。
- 开场层期间落地页 `inert`：视觉上被盖住，键盘也不该能钻进被盖住的控件。

**三个结构性决策**：

- **收益 → 能力 → 技术**：技术段固定在第 10 段、默认折叠，标题写「技术细节」而不是「AI 架构」。

  - 站内链接不指向不存在的文件；服务端路由必须在白名单内（只有 `demo` / `guest`）；

  - `prefers-reduced-motion` 下内容直出、不空屏、时间线连线直接显示；
  - FAQ 与技术段是原生 `<details>`，点击 summary 能真的展开；
  - 控制台零报错；

## 8. 维护约定

- 不得引入外链资源：无 CDN、无第三方字体、无图标包、无统计脚本。
  `index.html` 内联了打包后的 **Vue3 + three.js**（第十四轮起为粒子界面重新引入）—— 仍是本地内联、零外部请求；手势资源另在 `landing/fusion/mediapipe/`（不点按钮不请求）；
  `home.html` 依旧零第三方库。
- **公开页不得触发真实模型调用**：页面必须纯静态，示例 AI 内容只能是写死的文本并标明「依据当时的记录」。服务端侧另有 token 门 + 双配额兜底，但**公开页本身不该发请求**。
- 改完必须重跑四项：22 组对比度、6 视口布局与滚动、`prefers-reduced-motion`、关闭 JS。
- **开场动画的时序只改一个地方**：`IntroOverlay.vue` 里的 `EYE_T_Z0 / EYE_T_ZD`（其余 `T` 由它们推导）；

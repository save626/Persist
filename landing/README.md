# landing/ — 对外入口原型（未部署、未上线）

单文件落地页 + 覆盖层入场动画的原型。**不是最终站点**，也未接入应用域名。

- `index.html`：28826 B（gzip 9055 B）、995 行，内联 CSS / JS / SVG，**零外部请求**（系统字体栈，无 CDN / 统计 / 第三方字体）。
- `preview/*.png`：无头 Edge 渲染的自测截图（390×844 / 1280×900 / 1280×2600）。**自测证据，不是营销素材**，最终观感以真机与最终文案为准。

## 本地打开

直接双击 `index.html`，或在仓库根目录用任意静态服务打开。`file://` 下 CTA 的 `?mode=demo` / `?mode=guest` 是占位，接入应用子域后才生效。

跳过闸门：加查询参数 `?nogate=1`。

## 硬约束（改动前必读）

1. **零外部请求**：不得引入 CDN、第三方字体、图标包、统计脚本、第三方动效库。
2. **公开页面不触发真实模型调用**：示例 AI 内容必须是预生成的静态产物并标注「AI 生成」+ 模型 + 生成时间。
3. **渐进增强**：隐藏 / 位移样式只在 `html.js` 下生效；滚动揭示必须有非 `IntersectionObserver` 兜底；`<noscript>` 隐藏闸门。
4. **闸门不是内容门**：文案首帧可见，可点击 / 滚动 / `Esc` 跳过，`prefers-reduced-motion` 静态兜底，不做自动播放音频。

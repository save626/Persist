## 2. `index.html`：落地页实现要点（2026-11-19 重做）

**定位**：陌生人点开链接的第一屏。3 秒内看懂「这是什么、我能得到什么、我该点哪里」——
氛围由 3D 粒子流星雨承担，**不出现任何技术词**，不做弹窗 / 闪烁 / 视差 / 数字滚动。

**画面**：深空蓝黑舞台（径向渐变 + 72 px 极细网格 + 两团低饱和极光）+ `canvas#sky` 粒子层
+ 文案背后的柔和压暗（`.vignette`）。文字为静态 HTML，**关掉 JS 也完整可读**。

- **3D 粒子流星雨**（本页唯一的炫技点）：Canvas 2D + 标准针孔投影，不是贴图也不是假 3D。
  - 坐标：相机在原点沿 -z 看，流星在 `(x,y,z)` 里以恒定世界速度飞行，z 由 ≈1700 推进到 ≈260；
    投影 `k = FOCAL / z`（FOCAL = 820），`screen = center + world * k`。
    **纵深全部来自这行投影**：近处流星更粗、拖尾更长，远处更细更短。
  - 拖尾：每 26 ms 采一个点，最多 16 个点；按时间采样而不是按帧，帧率变化时长度基本一致。
  - **粗细公式必须写成 `k × 世界粗细`**（`bk * 2.0 * m.t`，钳在 0.5–4.2 px）。
    早期版本误写成 `k * 300`，所有粒子都被钳到上限 → 粗细完全一样，退化成「下雨」，纵深消失。
  - 分档批量描边：线段按 (透明度档 × 粗细档) 合并成 9 次 `stroke()`，
    避免每颗流星各描一次带来的调用爆炸；`globalCompositeOperation = 'lighter'`。
  - 方向带抖动（±0.20 rad）：整场同角度会看成下雨，随机偏一点才是流星雨。
  - 头部辉光只给 `k > 1.5` 的近处流星（数量很少），远景不画。
- **降级**：`prefers-reduced-motion` → 固定种子（mulberry32）造静态终帧；`document.hidden` 停 rAF；
  `resize` 180 ms 节流；`?still=1` 供截图；DPR 上限桌面 2 / 窄屏 1.5。
- **入场**：`.stagger` 一次性错峰淡入（85 ms 步进，只动 `opacity` / `transform`）。
  **只有 `html.js` 下才隐藏**，脚本没跑起来或 JS 被禁用时内容直接可见；另有 2 秒兜底强制显示。
- **CTA**：主「立即体验」→ `/app/?mode=demo`；次「了解更多」→ `home.html`。
  不再有「点击任意处进入」——普通用户点背景就走了，不如给明确按钮。


## 3. `home.html`：介绍首页实现要点

9 个段落（顺序即源码顺序）：首屏 `#top` → 问题 `#problem` → 怎么工作 `#how`（5 步）→ 三个模块 `#product` → AI 报告 `#report` → 长期视角 `#long`（7/30/90 天）→ 隐私 `#privacy` → 适合谁 `#who` → 内测 `#beta` → 页脚。锚点与导航一一对应，无失效锚点。

- **零图片**：所有图形都是 CSS 渐变、`box-shadow`、内联描边 SVG（`stroke` 系图标）。首屏「今日卡片」是纯 CSS 摆出来的示意，不是截图。
- **动效只用 `opacity` / `transform`**：导航 `is-stuck` 在 `scrollY > 12` 切换（rAF 节流）；`.reveal → .in` 由 `IntersectionObserver` 驱动，并有 `delivered` 兜底与首帧强制放行；`prefers-reduced-motion` 下全部直出。
- **仅两个产品入口**：`data-enter="demo"` 与 `data-enter="guest"` 交给同一个事件委托，分别进入 `/app/?mode=demo` 与 `/app/?mode=guest`。页面不存在 `product` / `beta` / `blank` / `owner` 入口；桌面构建不提供真实 AI 入口，完整产品只在作者自有移动端 App。

## 5. 验证方法（可复现）

无头浏览器容易骗人，判据必须来自**真实渲染后的测量**，不是「看起来对」：

- 工具：`app/node_modules` 里的 Playwright（`chromium.launch({ headless: true })`），直接开 `file://`，可 `evaluate`、截图、`emulateMedia`、`javaScriptEnabled:false`。
- **落地页一条命令**：`node scripts/check-landing.mjs`（加 `--shots` 顺带重拍 `landing/preview/landing-*.png`）。它断言：
  - 6 视口（1920/1440/1280/768/390/360）无横向滚动、标题与主 CTA 落在首屏内；
  - 入场动画跑完后所有 `.stagger` 元素 `is-in` 且 `opacity = 1`；
  - 关掉 JS 时标题、两个 CTA、说明、三个价值条、备案信息全部可见可点；
  - `prefers-reduced-motion` 下出静态终帧且画布非空；
  - 粒子数 > 0、渲染帧数 > 10（动画真的在跑）、窄屏粒子预算 ≤ 60；
  - 关键色对对比度（正文门槛 4.5）。
  页面内置 `?selftest=1` 会把真实测量值（粒子数、帧数、各元素包围盒）写进 DOM，脚本据此断言。
- 首页判据：6 视口（1920/1440/1280/768/390/844 横）无横向滚动、恰好 9 个 section、58 个 `.reveal` 全部进入且不透明、4 个 toast 都真的出现、降级路径（减动效 / 关 JS）内容完整、无控制台报错。
- 三处已知坑：① `--dump-dom` + `--virtual-time-budget` **不会**冲刷异步回调，`setTimeout` / rAF 里写的 DOM 永远看不到，只有加载期同步写入才算数；② `--screenshot` 在超高窗口（如 1920×8000）会挂死；③ 探针 HTML 页面里用字符串拼接构造结果文本（如 `'SYN-'+'OK'`），否则正则可能匹配到 `<script>` 源码里的字面量而误判。
- 另两条只读门禁：`node scripts/check-og-meta.mjs`（分享卡标签）、`node deploy/scripts/render-site-info.mjs --check`（备案占位一致性）。

## 8. 维护约定

- 不得引入外链资源：无 CDN、无第三方字体、无图标包、无统计脚本、无第三方动效库。
- **公开页不得触发真实模型调用**：页面必须纯静态，示例 AI 内容只能是写死的文本并标明「依据当时的记录」。服务端侧另有 token 门 + 双配额兜底，但**公开页本身不该发请求**。
- 改完必须重跑四项：22 组对比度、6 视口布局与滚动、`prefers-reduced-motion`、关闭 JS。
- 图片来源 `picture/` 不入库；`assets/` 里的派生 WebP 与 LQIP 入库。
- 文档分工：本文管**落地页与介绍首页的实现细节**；[`docs/落地页与入场动画方案.md`](../docs/落地页与入场动画方案.md) 管「跳转参数 + 跳过去之后的运行模式」；[`docs/网站设计层交接-2026-11-19.md`](../docs/网站设计层交接-2026-11-19.md) 是**重新设计的单一入口**。

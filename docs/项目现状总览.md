## 4. 数据与 AI 现状

- **持久化**：数据库 `persist-app`（版本 1）/ 对象仓 `mock-state` / 单记录 `persist-mock-state`；记录 = `{ id, schemaVersion: 1, savedAt, backup, snapshot }`；13 个状态切片合成一条记录，200 ms 防抖写盘，`pagehide` / `visibilitychange` 补写；读盘状态 `loaded / empty / unavailable / corrupt / unsupported-version`，异常退回纯内存且不清用户数据。代码在 `app/src/lib/persist-state.ts` + `persist-storage.ts`，`MockDataProvider` 对外契约未变。
- **数据丢失边界**：清站点数据、换浏览器/设备、无痕模式即丢；没有账号与跨设备同步；两个标签页同时编辑以最后写入为准。
- **AI**：全部为**前端 Mock**（界面标注「本地生成 · Mock 对话」），没有真实 DeepSeek 调用。`ChatEvent` 契约固定为 `stage('collect') → delta* → questions? → profilePatch? → stage('propose') → proposal? → warnings? → done`，档案写入必须过 `sanitizeProfilePatch()`。
- **长期计划**：生命周期 `draft → active → archived → active`（同时仅一个 `active`），已进入备份 0.2.0（含 `longTermPlans`，兼容 0.1.0）。

## 7. 主要已知限制

1. 无真实 AI、无真实服务端 API（鉴权/限流/日志/密钥管理都还没有）。
2. 数据只在本机浏览器，无账号、无同步、无跨设备。
3. 备份只能手动导出/导入，**没有「从备份恢复」按钮**；导入是整体替换且无撤销。
4. 「清空本机数据」只清当前浏览器这一条记录（步骤 7 已有入口），不是恢复出厂设置、也不影响其它设备。
5. 快照不是备份；提醒不触发系统通知；照片只存文件名。
6. 没有 Android 工程与 APK。
7. 主 JS 554.38 kB 超过 Vite 500 kB 提示线（`/plans` 可懒加载拆包）；3 条 lint 警告未清。
8. 服务器 root 密码登录可用、3389 开着，部署前需安全加固。
9. 域名未备案 ⇒ 现阶段只能 IP 直连内部验收，不得对外宣称域名可用。
10. 服务器 Node 20 无内置 `node:sqlite`，SQLite 需 native 编译或等 P4 选型。

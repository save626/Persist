**P4 终态方向已定稿**（2026-11-04，`docs/P4-数据层与AI综合分析设计方案.md`）：本地优先 + 服务端可检索副本（IndexedDB 权威 + 增量同步到 Fastify/SQLite，服务端 SQL 算数字、模型只写分析），拆成步骤 11（8d 数据历史化）→ 12（P4a 同步）→ 13（P4b AI 综合分析）→ 14（P4c 备份/导出/删除），**尚未实施**。注意前提：当前**只有学习记录是真实历史**（训练历史是 `FitnessPage` 演示常量、饮食只有今天、饮水无日期）。

## 4. 数据与 AI 现状

- **持久化**：数据库 `persist-app`（版本 1）/ 对象仓 `mock-state` / 单记录 `persist-mock-state`；记录 = `{ id, schemaVersion: 1, savedAt, backup, snapshot }`；13 个状态切片合成一条记录，200 ms 防抖写盘，`pagehide` / `visibilitychange` 补写；读盘状态 `loaded / empty / unavailable / corrupt / unsupported-version`，异常退回纯内存且不清用户数据。代码在 `app/src/lib/persist-state.ts` + `persist-storage.ts`，`MockDataProvider` 对外契约未变。
- **数据丢失边界**：清站点数据、换浏览器/设备、无痕模式即丢；没有账号与跨设备同步；两个标签页同时编辑以最后写入为准。
- **AI**：**AI 引导建档已接真实模型（步骤 8b）**：档案页开启 AI 数据授权 + 服务端 `/api/health` 可用时，前端经本站 `/api/chat` 调用 DeepSeek（流式回复 + 结构化抽取），每次真实调用约 2 次上游请求；未授权、无 Key 或服务不可用时自动回退本地规则 Mock，并在界面上如实标注来源（「DeepSeek 生成 · 经本站服务端代理」/「本地生成 · Mock 对话」/ 回退提示）。已用真实 Key 端到端验证（200、3.5 s、127 个 SSE 事件）；真实调用暴露模型给出过去日期的问题，已通过提示词注入 Asia/Shanghai 当天日期 + 前端日期兜底修复。
- **AI 报告（步骤 8c）**：报告页打开时探 `/api/health`，可用则 `POST /api/report` 让模型写 `title/status/summary/conclusions/actions/warnings`，**指标数字、依据条目、统计区间仍由前端按本地记录确定性生成**；请求只含「已授权 + 设置来源开关打开」的摘要，未授权模块为 `null`（不是 0）；不可用回退 Mock 并显示回退提示且徽标同步降级，响应不合契约则明确报错、不伪造报告。真实 Key 验证：完整摘要 2.7 s、只授权学习时无训练/饮食字样；首轮模型自行算出「再补水 0.5 L」⇒ 提示词已改为**禁止任何数值推算**并复验。**只有「今日简报」走服务端，`训练建议` / `学习观察` 仍打开本地已有报告。** `ChatEvent` 契约固定为 `stage('collect') → delta* → questions? → profilePatch? → stage('propose') → proposal? → warnings? → done`，档案写入必须过 `sanitizeProfilePatch()`；报告契约在 `server/src/contract.ts` 与 `app/src/lib/report-types.ts` 两处镜像。
- **长期计划**：生命周期 `draft → active → archived → active`（同时仅一个 `active`），已进入备份 0.2.0（含 `longTermPlans`，兼容 0.1.0）。

## 7. 主要已知限制

1. **AI 报告只有「今日简报」走服务端，指标/依据仍由前端生成，`训练建议` / `学习观察` 仍打开本地报告**；服务端无账号鉴权（只有按 IP 限流）、无额度/费用监控，开发期间联调用过的真实 Key 上线前必须轮换；服务端未部署。
2. 数据只在本机浏览器，无账号、无同步、无跨设备。
3. 备份只能手动导出/导入，**没有「从备份恢复」按钮**；导入是整体替换且无撤销。
4. 「清空本机数据」只清当前浏览器这一条记录（步骤 7 已有入口），不是恢复出厂设置、也不影响其它设备。
5. 快照不是备份；提醒不触发系统通知；照片只存文件名。
6. 没有 Android 工程与 APK。
7. 主 JS 564.70 kB 超过 Vite 500 kB 提示线（`/plans` 可懒加载拆包）；3 条 lint 警告未清。
8. 服务器 root 密码登录可用、3389 开着，部署前需安全加固。
9. 服务器 Node 20 无内置 `node:sqlite`；P4 用 SQLite 单文件库，驱动二选一待定（升级 Node 22 用内置 `node:sqlite`，或保留 Node 20 用 `better-sqlite3`），**不装 MySQL/MariaDB**（见 P4 方案 §4/§18）。
10. **P4 只是设计定稿、尚未实施**：现在 AI 只能看到前端拼出的单窗口摘要，做不到「检索全部历史做综合分析」；且训练/饮食/饮水/计划都还没有跨日历史，必须先做步骤 11（8d）。
11. **备案仍在中途**（阿里云初审已通过 2026-11-04，计划 2026-11-05 提交管局，备案号未下发）⇒ 现阶段只能 IP 直连内部验收，不得对外宣称域名可用、也不得给上线日期一个承诺。

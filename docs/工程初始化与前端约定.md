## 技术决策

| 领域 | 选择 | 说明 |
|---|---|---|
| Web 客户端 | React 19 + TypeScript + Vite 8 | 面向浏览器开发与后续 Android WebView/Capacitor 部署 |
| 路由 | React Router | 固定一级导航五项：今日、健身、饮食、学习、AI 报告；长期计划为 `/plans` 二级页，不进导航 |
| 样式 | Tailwind CSS v4 + CSS 设计令牌 | 已验收的 v3 视觉保留为完整 CSS，后续增量组件使用 Tailwind 或语义类 |
| 质量检查 | Oxlint + TypeScript + Prettier | 替代 ESLint；启动速度快，满足当前 React/TypeScript 静态检查 |
| 单元测试 | Vitest + Testing Library | 覆盖倒计时、统计与后续纯业务逻辑 |
| 端到端测试 | Playwright + 本机 Chrome | 同时验证桌面和安卓尺寸视口 |
| 数据 | 本机浏览器 IndexedDB（原生实现，未引入 Dexie） | 单记录 `persist-mock-state`，带 `schemaVersion` 迁移与未来版本只读保护；跨设备同步留给后续阶段 |
| AI | 后续服务端代理 | DeepSeek Key 不进入 Web 与 Android 包 |

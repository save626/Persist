## 1. 这份文档解决什么

「落地页」是本项目的**第一个对外入口**：陌生人点开链接看到的第一屏。它同时承担三件互不冲突的事：

1. 一句话说清这是什么（个人自用、本地优先的「计划 → 记录 → 复盘 → AI 分析」工具）。
2. 给两条跳转入口：**查看演示**（`?mode=demo`）与**自己体验**（`?mode=guest`）。
3. 讲清数据在浏览者自己手里，并把真实 AI 与桌面体验模式隔离开。

入场动画（闸门）只是这页的第 0 秒，不是独立产品。

## 2. 当前产品口径（2026-11-10 更新）

- **现状**：域名已购、阿里云备案初审 2026-11-04 通过、**备案号未下发**；生产只有 `http://<IP>/` 直连。2026-11-11 已部署落地页、产品介绍首页与 `/app/` 的 demo / guest 入口，仅内部调试，**未上线**。桌面落地页与产品介绍首页的视觉由另一 Agent 负责，本仓库只接入口路由。
- **产品决定**：完整 AI 产品（报告、简报、周报等全部 AI 能力）只在作者自有的移动端 `owner` 模式实现；桌面端不提供完整 AI 产品，只提供两个受控入口。web demo / guest 进入产品后，桌面侧栏与窄屏顶栏均提供返回 `/home.html` 的入口；mobile owner 不显示该网页入口。
- **合规边界**：面向用户提供生成式 AI 功能需要专门备案 / 安全评估与内容安全义务。桌面 `demo` 展示的是部署前真实生成并固化的只读报告快照，但上线前仍需完成合规复核，并在服务端补令牌门、来源限制与配额；不能把前端模式开关当成安全边界。

| 模式      | 数据                                                                                                                                          | AI 能力                                                                                                                                        | 入口                      |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| **demo**  | 完整预置演示数据，独立 IndexedDB                                                                                                              | **全部 AI 内容均在部署前真实生成并固化，部署后只读、零 `/api/*`**；AI 建档、晨间简报、服务端综合分析与三张今日观察卡均读取预生成快照；同步关闭 | 查看演示（`?mode=demo`）  |
| **guest** | 空白开始，独立 IndexedDB                                                                                                                      | **全部 AI 固定 Mock**，不请求 `/api/*`；同步关闭                                                                                               | 自己体验（`?mode=guest`） |
| **owner** | 作者自己的数据，原 `persist-app` 库；首启 / 清空为无业务占位的空白状态（饮水基线 0，AI 总授权保留开启，数据来源开关、提醒与每日简报默认关闭） | 完整真实 AI + 同步，真实 AI 不可用时降级为本地 Mock / 规则并标注来源；只由 `npm run build:mobile` 生成的 USB 移动端包提供                      | 移动端应用默认模式        |

## 3. 已锁定的决策

| 项目     | 结论                                                                                                | 理由                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 动画实现 | **纯内联 SVG** + `stroke-dasharray` / `stroke-dashoffset` 手写，**零依赖**                          | 体积、许可证、首屏预算；不引 three.js，不引 GSAP DrawSVG（付费 Club），不引 Lottie / vivus / anime.js |
| 动画文案 | **「记录，同一天」**（用户逐字指定，不得改写）                                                      | 一句话说清产品动作                                                                                    |
| 形态     | **覆盖层 overlay**（盖在落地页之上后再淡出），不是独立页面、不是视频、不是开场图                    | 无额外请求、无加载等待、可跳过                                                                        |
| 放行方式 | 约 **3 s 自动淡出** + 点击任意处 / 右上「跳过」/ 滚动 / `Esc`·`Enter`·空格 均可跳过                 | 不允许动画挡住想看内容的人                                                                            |
| 频次     | **每会话一次**（`sessionStorage: persist-gate-seen`），`?nogate=1` 可在截图与联调时绕过             | 反复出现会烦人                                                                                        |
| 无障碍   | `prefers-reduced-motion` 下动画取消、1.2 s 后直接放行；`<noscript>` 直接隐藏闸门                    | 尊重系统偏好；无脚本时不能有黑屏                                                                      |
| 内容优先 | 文案在**第一帧**就可见，动画只是装饰，**LCP 是文案不是动画**                                        | 动画不得成为内容门                                                                                    |
| 音频     | **不做**自动播放声音                                                                                | 静音环境、无障碍、浏览器策略                                                                          |
| 分享图   | **独立静态图** 1200×630（不靠动画截帧）                                                             | 社交平台不播动画                                                                                      |
| 视觉母题 | **「一条线」**：闸门画一条线；能力图标同一笔画线稿（1.5 px 圆头）；章节分隔线、报告卡片都延续该母题 | 一个母题贯穿，避免拼贴感                                                                              |

## 5. 工程约束（可核对的硬指标）

- **零外部请求**：系统字体栈（`-apple-system` / `PingFang SC` / `Segoe UI` …），无 CDN、无第三方字体、无统计脚本、无图片外链。
- **体积预算**：首屏 ≤ 150–200 KB；HTML + CSS + JS ≤ 60 KB（gzip）。按流量计费的环境里，这条是成本约束不是审美偏好。
- **视觉刻度**：单强调色；8 pt 间距网格；卡片圆角 20–24 px；章节间距 120–160 px；标题 56–80 px、字距 `-0.02em`；浅色/深色双套（`prefers-color-scheme`）；最大宽度约 1100 px。
- **渐进增强红线**：JS 关闭时内容必须完整可读。具体做法：隐藏/位移样式只在 `html.js` 下生效，`<noscript>` 隐藏闸门，滚动揭示有非 `IntersectionObserver` 兜底。

### 6.3 DOM 事实（无头导出）

- `<html lang="zh-CN" class="js">`：`js` 类由内联脚本注入，源码里没有 → 说明隐藏样式只在 JS 在场时生效；
- 闸门关闭后为 `#gate.is-gone[aria-hidden="true"][style*=display: none]`；
- 23 个 `.reveal` 中 **5 个**已加 `.in`（首屏可见块），说明揭示逻辑真实投递而非全部隐藏；
- `?mode=demo` 出现 3 次、`?mode=guest` 2 次（CTA 双入口齐全）。

### 6.4 原型阶段修掉的两个真问题（改动前必读）

1. **无脚本内容不可见**：`.reveal` 原本无条件 `opacity:0`，JS 不执行时整页空白。改为**只在 `html.js` 下隐藏**，并由内联脚本加 `js` 类；闸门用 `<noscript>` 直接隐藏。
2. **`IntersectionObserver` 不投递时内容永久隐藏**：某些环境（含无头渲染的时间预算模式）观察者可能永不回调。加 `delivered` 标志 + 1200 ms 兜底 `revealInView()` + 常驻 `scroll`/`resize` 被动监听，确保任何情况下内容最终可见。

## 10. 维护约定

- 改桌面落地页的文案或结构后必须由该 Agent 重跑其渲染与联调检查；本 Agent 只改跳转后的 App 运行模式。
- **不得引入任何外部请求、第三方动效库或图标包**；新增装饰一律内联 SVG/CSS。
- **不得把计划写成现状**：demo 的全部 AI 内容均为部署前快照，部署后只读且不产生 AI 请求；guest 的 AI 全部为 Mock，同样零 `/api/*`。
- 任何新增数字都必须可复核（来自脚本实测），不得估值充数。

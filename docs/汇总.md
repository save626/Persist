**「OG 卡不是页面」是最容易搞混的一点**：别人分享链接时，平台爬虫抓 `<head>` 的 `og:*`，
在**对方那边**拼出卡片。`landing/og/` 是只在本机用的设计源目录，**永不上线**；
唯一对外产物是 `landing/assets/og-card.png`。

```

landing/index.html                app/    React 产品本体
landing/home.html                 server/ Fastify + AI 代理 + 数据层
landing/og/ + assets/og-card.png  shared/ 跨端契约
```

**唯一的跨界耦合**：`app/src/components/AppShell.tsx` 两处 `href="/home.html"`
（「返回首页」/「首页」）。`landing → app` 是单向跳转；`app → landing` 只有这两行 href。

## 2. 入口结构与三种运行模式

```text
域名 / IP
  └─ /                  落地页（开场动画 → 落地页主体）
       └─ home.html      产品介绍首页 —— 唯一的产品入口
            ├─ 查看演示 → /app/?mode=demo
            └─ 自己体验 → /app/?mode=guest
产品内「返回首页」→ home.html
完整产品 → 作者自有移动端 App（USB 安装 build:mobile 包）
```

| 模式 | 数据 | AI 能力 | 入口 |
| --- | --- | --- | --- |
| **demo** | 完整预置演示数据，独立 IndexedDB | 全部 AI 内容**部署前生成并固化**，部署后只读、**零 `/api/*`**；同步关闭 | 查看演示 |
| **guest** | 空白数据，独立 IndexedDB | 全部 AI 固定 **Mock**，零 `/api/*`；同步关闭 | 自己体验 |
| **owner** | 作者自己的库 | 完整真实 AI + 同步，不可用时降级并标注来源 | 只存在于 `build:mobile` 的 USB 包 |

- 网页构建（`npm run build`）**任何输入都解析不出 owner**：不带参数 / 非法参数 / `mode=owner` 一律回落 guest。
- `?mode=` 写入 `sessionStorage`；构建隔离与独立 IndexedDB 只防误操作与串库，**不是服务端鉴权**。

## 3. 硬约束（不可回退）

1. **零外部请求**：不引 CDN、第三方字体、图标包、统计脚本、第三方动效库；装饰一律内联 SVG / CSS。
2. **纯静态**：公开页不得触发任何真实模型调用；示例 AI 内容只能是写死文本并标明「依据当时的记录」。
3. **不得编造备案号**：页脚由 `deploy/scripts/render-site-info.mjs` 从 `deploy/site-info.json` 注入，
   `icpNumber` 已填（2026-11-26 下发），`policeNumber` **当前为空**（公安备案审核中）；
   留空即**不渲染任何内容**（不显示占位文案）；**卡面与 `<head>` 内不得出现任何编号**。
4. **上线口径**：站点已上线，可称「已上线」；但**不得宣称「正式发布 / 开放注册」**
   ——网页端仍只有 `demo` / `guest`，真实 AI 与同步只在作者自有移动端 debug 包里。
   **公安备案号未下发前，任何页面都不得出现该编号或占位**；通过后 30 日内补挂公网安备号 + 图标。
5. **渐进增强**：无 JS 时内容完整可读——隐藏/位移样式只在 `html.js` 下生效，揭示效果必须有超时兜底。
6. **`app/` 视觉冻结**：改动 `app/` 任何页面文案/结构要重跑 `visual:check` 并请用户双端验收；
   本层不碰 `app/`，但改 `home.html` 的产品描述时需与 `app/` 实际能力一致。
7. **公开仓库脱敏**：不提交真实公网 IP（写作 `121.196.*.*`）、密码、API Key、`.env`、`*.local.md`、构建产物。

**入口专属约束**：

- **落地页不得有任何直达产品的入口**。`scripts/check-landing.mjs` §0 静态扫全部 `href`/`src`，出现 `/app/` 直接判失败。
- 落地页两个 CTA 都指向 `home.html`（主 → 首屏，次 → `home.html#story`）。
- 首页只保留 `demo` / `guest` 两个真 `<a href>`，不得新增 `product` / `beta` / `blank` / `owner`；关掉 JS 也能进产品。
- **必须点击才交棒**，不做自动跳转（含移动端）。
- 落地页主体是一张安静的浅灰蓝纸，**没有常驻流星雨**；流星只在开场层出现。

## 5. 开场动画

### 5.1 时间线（唯一事实源：`IntroOverlay.vue` 的 `T` + `EyePlayer.js` 的 `CFG`）

| 时刻 | 动作 |
| --- | --- |
| 0 – 0.9s | 近黑 `#010203` 淡入，只看得到皮肤纹理 |
| 0.9 – 6.2s | 眼睑睁开、眨眼，灰蓝三色字符画虹膜/瞳孔露出，居中 |
| **5.2s** | 预热粒子舞台（建 WebGL、编译着色器、先渲几帧）；`is-particle` 一并加上，CSS 的 `opacity`（2.6s）与 `mask-size`（3s）从这里开始走 |
| **6.2s** | 瞳孔推进开始 → 字符画 0.55s 淡出、星轨+流星 1.5s 淡入；同帧 `revealParticle()` 起 JS 侧的缩放 `0.4→1`（3s）与随后的呼吸 |
| **9.2s** | 融合界面壳淡入（花瓣/圣诞树、开启手势、全屏；**无颜色选择器**）+ 一次性手势提示（5.2s 后消失） |
| **9.4s** | 推进结束，进入无手势自动呼吸 |
| 9.4s 后 | 花瓣 16s 一圈自动呼吸；「点击任意位置进入」常驻，点空白交棒（按钮都 `stopPropagation`） |

`T = { warm: 5.2, meteor: 6.2, particle: 6.2, ui: 9.2, wait: 9.4 }`，由
`EYE_T_Z0 = 6.2` / `EYE_T_ZD = 3.2` 推导。**改眼睛时长只动这两个常量；不要在 CSS 里写死秒数。**

**无手势自动呼吸**：16s 一圈（三角波过**双重 smoothstep**，两端停留、中间快过）+ 逐帧低通 `approach(0.05, dt)`，
由开场自己驱动 `setDisperse`，**不依赖场景内部的 `autoCycle`**（实测交给场景后 `aDisperse` 恒为 0）。
有手势时自动呼吸立即让位。

### 5.2 眼睛层

- 来源：上游 `iremcnar/eyeTutorial`（Python，未声明许可）→ `third_party/eyetutorial-replica/engine.js`
  （**逐字节复制，不许改**），由 `scripts/inline-intro-engine.mjs` 内联，`--check` 校验一致性。
- 观感基线是 Python 原版 9 格分镜（`third_party/.../reference/preview-python-original.png`），网页复刻版字符过密不能当基准。
- 疏朗度四要素（都在调用侧）：网格 **78×30**、字符格 **8×15**、字号 `cellW×1.75`、不用 `bold`；引擎 `q` 已含 `×1.15` 不得重复乘。
- 居中（双保险）：① 画布 `position:absolute; inset:0; margin:auto`（父级 flex 对绝对定位子元素无效，这是「偏心」真正根因）；
  ② 调用侧包装 `renderer.gaze`，推进阶段恒返回 `(0,0)`。
- 灰蓝三色：深底 `#010203` 保留；`_palette()` 把引擎原生 RGB 重映射为瞳孔 `#1a2a36` / 虹膜 `#467692` / 巩膜 `#c7dae6`。
  **不要退回单蓝亮度映射，也不要恢复琥珀原色。**
- 心形星云：`T_HEART=1e6` 只禁「心形」，云雾本体还要 `T_ZD < 3.5` + `ZEND=20` 才彻底干净。

### 5.3 星轨与流星（`src/three/MeteorField.js`，Canvas 2D）

- **星轨**：几何圆弧绕画面上方极点公转，4 档亮度 × 3 段渐弱。**130–220 条**（按面积自适应，移动端 ×0.55）、
  弧长 0.06–0.19rad、亮度分档 `0.22/0.36/0.52/0.72`、公转 0.0025–0.011 rad/s。
- **桌面流星**：上限 **40**、生成间隔 0.065s、寿命 1.6–3.2s、速度 300–620 px/s、
  角度 118–148°、长度 110–260px、冷蓝 hue 192–216。
- **移动端流星**（`MOBILE` 常量）：**随机分布 + 高密度** —— 上限 **46**、补充 **0.020s**、
  角度 **104–128°**（更偏竖直，否则斜线走不到屏底就出界）、速度 250–360、
  长度 = **屏宽 × 0.20–0.44**（绝对像素在窄屏上会顶到 2/3 屏宽）、寿命 2.0–3.4s。
- 出界判定是 `x < -长度 || y > H + 长度`。**不要放宽到 2 倍**——那会让池子里大半颗在屏外空转
  （参数写 34 颗、屏幕上只有 5 颗）。
- 早先试过「等距点阵」（5 轨 × 6 颗、同向同速），用户否掉「太规整」，不要再回退。
- `useBloom` / `particles` 是兼容字段（语义：「PC 完整效果」/ 流星数组），验收脚本还在读，**别删**。

### 5.5 粒子层与融合界面壳（桌面端）

- 复用 `gesture-particle-fusion-20261121/src/stage.js` + `core/gestures.js` + `core/hand-tracker.js`，
  开场通过 Vite alias `@fusion` 引用，**没有第二份粒子代码**。
- 两场景：`stage.loadScene('flower' | 'lights')`。花瓣无手势时定格完整六瓣 + 呼吸；有手势时张手散开 / 捏合聚合；
  圣诞树张手炸散 / 握拳收树 / 手左右旋转。
- **手势不自动开启**：不点按钮不 `import()` MediaPipe、不申请摄像头、不请求资源（实测点击前 0 个 `fusion/mediapipe` 请求，点击后 4）。
- **全屏 = 只看画面**：状态栏/提示/关闭按钮一律 `opacity:0` + `pointer-events:none`（`transition:none`）；
  **全屏期间点击不交棒**，ESC 退出后恢复。
- 层级：眼睛(2D) → 星轨+流星(2D，近黑底) → 粒子(WebGL，透明) → 界面壳。
  （2026-11-23 起没有星空照片底图层。）

**三条硬教训（实测踩出来的）**：

1. 定格时扩散度必须是 0。`disperse` 不是「松一点」，而是把粒子插值到满屏随机点——开到 0.2 六瓣就会糊成云。
2. 粒子要在推进开始前预热，否则淡入起点会被 WebGL 初始化拖后 0.3–1s。
3. 验收要按「起播秒」采样：单文件 1 MB 的 `load` 也要 2–3s，`state().elapsed` 才是真相；
   headless 里 rAF 会饿住 `setTimeout`，所以读 `getAnimations()` 的过渡对象（`mask-size 3000ms / opacity 2600ms`）判在跑。

### 5.6 降级、暂停与清理

- **移动端**：UA + `pointer:coarse` + 视口宽度三重判定；不挂粒子层、**也不显示界面壳**（按钮点了没东西可切），
  保留星轨/流星 + 点击进入。
- **`file://`**：粒子照常，但「开启手势」按钮隐藏（摄像头要安全上下文），场景切换与全屏可用。
- **页面不可见**：`visibilitychange` 暂停渲染。
- **关闭动画按钮**：全程可见，点击立即 `dispose()` 释放资源再交棒。
- **跳过开场**：`prefers-reduced-motion` / 动效开关关闭 / `?intro=0` / `?still=1` → 完全不播；无 JS 时开场层整层 `hidden`；开场期间落地页 `inert`。
- **排障入口**：控制台 `__introDiag()` 返回 viewport / coarsePointer / particleEligible / stageReady / stageError / uiVisible / barRect / hitAtBarCenter / elapsed。

## 6. 落地页与介绍首页

**落地页**：科技展示型，不是说明书。只留项目名、slogan「把每天的碎片写下来，晚上看懂自己」、几个关键词；

+ 眼睛标记（入场眨一次眼、虹膜跟随光标微动，偏移 ≤3.2px）。
产品令牌：纸底 `#F4F7F9`、`--deep #467692`、`--green #6D9FBD`；`--muted/--faint` 为对比度达标用 `#55616D/#616D79`。
不做 Shader / WebGL / 视差 / 滚动依赖 / 频闪 / 自定义光标 / 数字滚动；仿真终端与 ASCII 字符流已移除。

## 8. 手势

### 8.1 数据流

`core/hand-tracker.js`（MediaPipe HandLandmarker，本地 wasm + 模型，检测上限 30fps）
→ `core/gestures.js`（产出 `palm / fist / pinch / spread / fingers / pos / rot`，EMA 时间常数 **0.04s**，丢手保持 450ms）
→ 场景只做映射。**场景不再各自解析 21 点，也不要叠第二层平滑。**

### 8.2 阈值（2026-11-24 真手标定）

`tension.js` 的 `FINGER_RANGES`（ratio = `|tip-wrist| / |mcp-wrist|`）：

| 指 | closed → open | weight |
| --- | --- | --- |
| thumb | 1.45 → 2.35 | **0**（握拳时比值反而更大，无区分度） |
| index | 0.88 → 1.90 | 1.0 |
| middle | 0.82 → 1.98 | 1.0 |
| ring | 0.75 → 1.98 | 0.9 |
| pinky | 0.72 → 1.78 | 0.7 |

- `palmSpread` 区间 **0.88 → 2.30**；`SPREAD_THRESHOLD` 仍是 `{ closed: 0.32, open: 0.66 }`；
  `DEFAULT_MIX` = `ratio 0.72 / spread 0.20 / curl 0.08`（缺失项会重新归一化）。
- 捏合：`clamp01((1.1 - d) / 0.8)`，`d` = 拇指尖↔食指尖距离 / 掌宽。
- **换手、换摄像头、换分辨率必须重标定**，这些常量只对一只手上最优。

### 8.3 聚合信号：`closingOf(g) = max(fist, pinch)`

场景里 `disperse` / `target` 一律用 `1 - closingOf(g)`，**不能只看 `palm`**：
`palm` 是四指 ratio 的加权平均，**两指捏合**（拇指+食指、其余三指伸开）只能把它压到 ~0.7，花不收。
这是 2026-11-24 真机验收暴露并修掉的问题，`shoot.mjs` 与 `intro-stage/scripts/check.mjs` 都有回归用例。

### 8.4 标定页

`cd gesture-particle-fusion-20261121 && node serve.mjs 4190` → `http://localhost:4190/calibrate.html`：
点开始授权摄像头 → 张开 / 握拳 / 捏合**各保持 2.5 秒** → 报告给出每指 p5/p50/p95 与
「握拳 p95 作 closed、张开 p5 作 open」的建议值，末尾可直接粘贴。
页面会自动丢弃每次记录的前 **600ms** 过渡帧（第一次实测就是被过渡帧坑了）；
控制台 `window.__calibrate.selftest()` 用合成样本验证统计与建议逻辑。

## 13. 踩坑速查（跨子系统）

- **headless 的时间不可信**：`load` 就要 2–3s，rAF 会饿住 `setTimeout`；一律按 `elapsed` 采样。
- **沙箱会拦子进程**：Playwright 起 Chromium、`git push` 的 `ssh`、`node --test` 都会 `spawn EPERM`，放宽一次即可，不是网络问题。
- **不要用 PowerShell 的 `Get-Content -Raw` + 字符串替换改含中文的源码/文档**（易变乱码）；用编辑工具或显式 `-Encoding utf8`。
- **`landing/index.html` 是构建产物**，手改会被下次构建覆盖；`landing/fusion/` 同理。
- **时间线只在 `EYE_T_Z0 / EYE_T_ZD` 改**，其余由它们推导；CSS 里不写死秒数。
- **`sceneId` 必须是 `ref`**（普通 `let` 不触发重渲染，表现为「只有花瓣高亮、切换后不跟随」）。
- **`disperse` 中间态很难看**：要么 0，要么接近 1；呼吸曲线两端停留、中间快过。

## 5. 可访问性

- 可点击区域不小于 44×44px；焦点态必须清晰可见。
- 表单控件必须有 label 或可访问名称；状态不能只靠颜色区分，需配文字或图标。
- 禁用、加载、错误三种状态必须有明确反馈；确认类操作必须可取消。

## 6. 非功能要求

- 性能：中端 Android 首屏可交互 < 2 秒；本地保存反馈 < 200ms（当前实现 200ms 防抖落盘）。
- 离线：除 AI 与服务器备份外，全部核心功能离线可用；AI 不可用时记录能力不受影响。
- 兼容：桌面 Chrome / Edge；Android 目标机型（Safari / Firefox 未列为目标）。
- 可靠性：单条记录失败不破坏已有数据；导入失败不覆盖原数据；迁移失败可回退（当前为未来版本只读保护）。
- 隐私：Key 仅存服务端；只发当前分析所需的摘要；未授权模块对 AI 不可见（`digest` 为 `null`）；日志不记录请求正文与档案内容。合规口径（备案号下发前不得用域名对外服务）见部署文档 §4。
- AI 成本：超时 / 限流 / 5xx 有限重试；同一数据版本可缓存（**步骤 13 的缓存键是服务端 `dataRev`，命中直接返回 `cached: true` 且不调模型；`force: true` 重新生成、**成功后才删旧缓存**）；超长历史只发聚合（P4 由服务端 SQL 聚合，**模型看到的只有事实包，不看到原始记录**）；每次报告记录模型名、提示词版本、耗时。综合分析有**独立限流**（默认 6 次 / 5 分钟），不与同步轮询共用额度。
- 综合分析口径（步骤 13，前后端共用 `shared/src/contract/analysis.ts`）：成功响应**平铺无包裹层**；正文里的每个数字都必须能在事实包 `JSON.stringify(facts)` 中找到（**数字白名单**），否则服务端按 `invalid_response` 拒绝且不归档；无 Key / 上游超时按规则降级为 200 + `origin: "rules"` + `model: null`，界面必须如实标来源；每日简报 job 默认关闭，且读的是**同步上来的** `settings.dailyBrief`（服务器环境变量只兜底）。
- 时间：默认 `Asia/Shanghai`；`dateKey` 为 `YYYY-MM-DD` 本地日期键，聚合与边界判断都用它。
- 备份：JSON 备份含 `version` / `exportedAt` / 实体数组（当前 0.3.0，含 `longTermPlans` / 按日历史字段，兼容 0.1.0 / 0.2.0）；保留策略见 P4 §12。
- 运行模式（2026-11-10）：网页 `npm run build` 只允许 `demo` / `guest`，无参数、非法参数或 `mode=owner` 一律回落 `guest`，web 解析层永远不能返回 `owner`；作者自有移动端使用 `npm run build:mobile` 生成 `app/dist-mobile`，默认 `owner`。`demo` 预置完整数据，报告、简报、AI 建档与长期计划均在部署前真实生成并固化；部署后只读、零 `/api/*`、同步关闭；`guest` 从空白开始，全部 AI Mock 且不请求 `/api/*`。demo / guest 由查询参数进入并写入 `sessionStorage`，三者使用独立 IndexedDB。构建隔离是产品面边界，不是服务端鉴权；虽然网页 demo 零 `/api/*`，服务端 AI 接口仍可被直接调用，上线前必须有 token 门、来源限制与配额。桌面落地页与产品介绍首页由另一 Agent 负责，本仓库不改其视觉。
- 渐进增强：无脚本时内容必须完整可读——隐藏 / 位移样式只在 `html.js` 下生效；任何依赖 `IntersectionObserver` 的揭示效果都必须有超时兜底 + 常驻 `scroll` / `resize` 回退（2026-11-09 落地页原型踩过这两个坑）。

## 9. 术语

| 术语                      | 解释                                                                                                                                    |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 今日闭环                  | 计划 → 记录 → 聚合 → 复盘构成完整一天                                                                                                   |
| 本地优先                  | 写入先落本地库，服务器不可用不影响使用                                                                                                  |
| 结构化 AI 输出            | 固定 schema 的 JSON 返回，便于校验与用户确认                                                                                            |
| 确认式修改                | AI 不能直接写数据，必须用户确认后落库                                                                                                   |
| 软删除                    | 保留 `deletedAt`，便于撤销、备份与同步                                                                                                  |
| Outbox                    | 本地待同步操作队列（P4 步骤 12d 已落地：`app/src/lib/sync-queue.ts` + `persist-sync` IndexedDB；同步默认关闭）                          |
| 视觉 Token                | 颜色、字体、间距、圆角、阴影等统一设计变量                                                                                              |
| 事实包（`ReportFactsV2`） | 步骤 13 起服务端按 7/30/90 天窗口用 SQL 聚合出的事实集合，模型只读它写文字                                                              |
| 数字白名单                | 模型正文出现的每个数字必须存在于事实包中，否则按 `invalid_response` 拒绝、不归档                                                        |

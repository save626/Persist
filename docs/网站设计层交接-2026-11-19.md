## 1. 网站设计层是什么

三个交付物，各司其职：

| 交付物                    | 路径                        | 职责                                                   | 上线      |
| ------------------------- | --------------------------- | ------------------------------------------------------ | -------- |
| **落地页**                | `landing/index.html`        | 陌生人点开链接的第一屏。星空入场动画 +「Hello world」手写揭示 | 是       |
| **产品介绍首页**          | `landing/home.html`         | **12 段**讲清产品是什么、怎么用、适合谁。两个产品入口。面向普通用户，技术段折叠后置 | 是       |
| **OG 分享卡**             | `landing/assets/og-card.png` | **链接的封面**。爬虫抓 `<head>` 的 `og:*` 生成，不是给人打开的页面 | 是（一张图） |

**「OG 分享卡不是页面」——这是最容易搞混的一点。**

别人分享 `https://wpersist.top/` 时，微信 / X / Facebook 的爬虫去抓那个页面的
`<head>`，读到 `og:title` / `og:description` / `og:image`，然后在**对方那边**拼出一条卡片。
**你分享的永远是链接，卡片是对方那边生成的。**

- `landing/og/` 是**设计源目录**（本机生产这张图的工具），**永不上线**；
- 唯一对外产物是 `landing/assets/og-card.png`。

## 4. 三个交付物的现状与已知问题

### 4.1 落地页 `index.html`

**画面**：`canvas#sky` 固定满屏，每帧先整体 `clearRect`，再重画背景、星轨、流星。

- **星轨**：不是累积拖影，每帧按当前角位置现算圆弧 `arc(cx, cy, r, a - len, a)`。
  每段 `arc` 前必须先 `moveTo` 到弧起点，否则会连出杂乱直线段。按亮度分 9 档
  批量 `stroke()`，避免 200 多次单独描边。
- **流星**：移植自 `产品/流星雨效果.html`——20 条、4 段 `hsla` 渐变、`width*7`
  径向辉光、`globalCompositeOperation='lighter'`、`lineCap='round'`；
  `spawnInterval 0.13 s`。指针按下时朝点击方向补一颗。
- **文案揭示**：移植自 `产品/Hello world Sacramento 水平路径.html`——
  `#textLine` 路径上跑 `textPath`，`<mask>` 里粗描边路径的 `stroke-dashoffset`
  沿路径推进，笔尖用 `getPointAtLength` 跟随，4400 ms、`easeInOutCubic`。
- **两个移植时必须改的坑**：
  1. `stroke-dasharray` / `dashoffset` 写在 `<use>` 上**不会可靠传给影子副本**，
     导致遮罩永远整条实心、文字第一帧就全露。遮罩里必须是**真 `<path>`**。
  2. 遮罩描边被放大约 2.8 倍字高，若沿用参考文件的 `stroke-linecap:round`，
     圆头半径 ≈ 262.9 单位、占 `MASK_LEN 1038.8` 的 **25.3%**，等于整段揭示恒定
     提前四分之一。必须改 `butt`。
- **底图保真**：源图 3000×2788 / 2.1 MB。WebP `quality=84, method=6`，
  宽版 1280/1920/2560/3000、竖版 720/1080/1440，按视口宽与宽高比选档，
  **断言 `w <= 源宽`，永不上采样**。LQIP 86 B 内联 + 纯色兜底。
  放弃 AVIF：同码率下细节保留只有 60.9%。
- **降级**：`prefers-reduced-motion` → 静态终帧、文案立刻可见；`document.hidden`
  停 rAF；`resize` 180 ms 节流；`<noscript>` 纯文本兜底；DPR 上限 2。

**已知问题**：
- **Hero 手机图仍是 CSS/SVG 示意图**，不是真实截图 → 上线前换真实截图。
- 星空底图 5.4 MB 是 `assets/` 的绝大部分（7 档 WebP）。

### 5.1 三条命令

```bash
# ① OG 标签自检（只读，退出码非 0 即失败）
node scripts/check-og-meta.mjs
node scripts/check-og-meta.mjs --url http://<IP>/ --image-url http://<IP>/assets/og-card.png

# ② 备案号注入一致性（只读）

# ③ 渲染 OG 卡（改文案或改构图后必须重跑）

node scripts/render-og-card.mjs --variant a  # 只渲染变体 A
```

**`check-og-meta.mjs` 校验项**（任一不通过 → 退出码 1）：

- `og:*` / `twitter:*` / `canonical` 全部存在，`og:image` 与 `twitter:image` 指向同一张卡
- `og:image` 必须是**绝对 URL**（相对路径微信抓不到）
- `og:image:width/height` 必须是 1200 / 630，且与实际 PNG 尺寸一致
- `twitter:card` 必须是 `summary_large_image`
- **`<head>` 内不得出现任何备案编号**

网络层抓不到 `og:image` 时按**告警**处理（域名未解析是备案号下发前的预期状态），
HTTP 4xx/5xx 才算错误。

> **为什么不再用 Edge headless 渲染**（旧命令已废弃）：
> Edge 无头模式是多进程 + 命名管道 IPC，在受沙箱限制的 shell 里会**静默失败**——
> 命令返回 0 但截图不落盘，很容易误以为成功。Playwright 单进程可控，
> 脚本渲染后会校验产物确实落盘，失败立刻退出码 1。

### 5.2 视觉验证：判据必须来自真实渲染后的测量

**无头浏览器容易骗人**，「看起来对」不算数。

- 工具：`app/node_modules` 里的 Playwright（`chromium.launch({ headless: true })`），
  直接开 `file://`，可 `evaluate`、`fullPage` 截图、`emulateMedia`、
  `javaScriptEnabled:false`。
- **落地页判据**：6–8 个视口下文案居中（`offX/offY = 0`）、`fontSize` 145.7–146.4 px
  稳定、流星数达上限、星轨段数在区间内、提示语出现；`prefers-reduced-motion` 下出终帧；
  视口宽高比正确选到宽版 / 竖版底图且无上采样。
- **首页判据**：6 视口（1920/1440/1280/768/390/844 横）无横向滚动、恰好 9 个 section、
  58 个 `.reveal` 全部进入且不透明、4 个 toast 都真的出现、降级路径（减动效 / 关 JS）
  内容完整、无控制台报错。
- **OG 判据**：几何自检 `?selfcheck=1` 读回版式量值——舞台 1200×630、
  `scrollWidth/Height` 不超 1200/630、无元素 `overflowX > 0`、母题不压页脚分隔线；
  像素校验——尺寸正好 1200×630、内容距四边 ≥ 60 px、强调色像素 ≥ 20。

**三处已知坑**：

1. `--dump-dom` + `--virtual-time-budget` **不会**冲刷异步回调，
   `setTimeout` / rAF 里写的 DOM 永远看不到，只有加载期同步写入才算数
2. `--screenshot` 在超高窗口（如 1920×8000）会挂死
3. 探针 HTML 里用字符串拼接构造结果文本（如 `'SYN-'+'OK'`），

> **像素对比的额外坑**：星空动画会让同一份 `index.html` 两次渲染相差约 5 万像素。
> 验 OG 或落地页的**确定性**时要用 DOM 与计算样式对比，不要用像素对比。

22 组对比度 / 6 视口布局与滚动 / `prefers-reduced-motion` / 关闭 JS。

### 6.1 Nginx 路由（`deploy/nginx/persist.conf`，与服务器实际一致）

```
location = /index.html          → 精确匹配落地页
location = /home.html           → 精确匹配介绍首页
location ~* "^/(assets|design)/" → 静态直出（含 og-card.png，走长缓存规则）
location ^~ /app/               → React web，SPA fallback 到 /app/index.html
location /                      → 兜底 try_files $uri $uri/ /index.html
```

> **注意**：兜底 `location /` 会把 `/.well-known/acme-challenge/<token>` 回退成

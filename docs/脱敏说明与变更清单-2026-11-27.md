## 1. 判定口径

脱敏分三层，**不是所有"看着像秘密"的东西都该抹掉**——抹掉运维文档要用的真值，
文档本身就失去价值，反而制造"文档在骗人"的假象。

| 层 | 定义 | 本轮处置 |
| --- | --- | --- |
| **A 类·必须抹** | 凭据、口令、个人身份信息、真实公网 IP | 已抹或已确认为零 |
| **B 类·要泛化** | 基础设施指纹、运行时内部标识（会随时间失效且指向具体机器/实例） | 已泛化为状态描述 |
| **C 类·必须留** | 法定公示信息、对外公开信息、运维必需路径 | 保留并说明理由 |

**C 类保留清单（重要，别误删）**

| 内容 | 为什么必须留 |
| --- | --- |
| ICP 备案号 `豫ICP备2026060824号` | **法定公示**：工信部要求网站底部显著位置展示并链接工信部。抹掉即违规 |
| 域名 `wpersist.top` | 对外公开；ICP 公开查询即可反查，遮蔽无意义 |
| 服务器内部路径（`/etc/persist/server.env`、`/var/lib/persist/…`） | 部署文档的唯一操作依据。路径本身**不授予任何访问权限**（真正的门是 SSH 公钥 + `600` 权限 + 凭据门） |
| 服务名 / unit 名（`persist-server.service` 等） | 同上，是运维操作对象 |
| 第三方库的 Apache-2.0 许可与上游来源 | 法律义务 |
| 部署流程、命令、验收记录 | 文档的价值所在 |
